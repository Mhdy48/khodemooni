# خیاط خودمونی

سایت دوزبانهٔ آتلیه با دو ورودی مستقل Vite ساخته می‌شود. متن و HTML فارسی در `index.html` و متن و HTML عربی در `ar/index.html` قرار دارد. شناسهٔ بخش‌ها در هر دو صفحه مشترک است تا لینک‌ها و تعاملات روی هر دو زبان کار کنند.

## اجرای محلی

پروژه با Node.js 26 و npm 11 آزمایش شده است. در پوشهٔ پروژه اجرا کنید.

```sh
npm ci
npm run dev
```

فارسی در مسیر `/` و عربی در `/ar/` باز می‌شود. `npm run build` هر دو صفحه را در `dist` می‌سازد و `npm run preview` خروجی را محلی نمایش می‌دهد. هنگام انتشار، `SITE_ORIGIN` را مطابق `.env.example` تنظیم کنید تا لینک‌های canonical و hreflang با دامنهٔ عمومی ساخته شوند.

## توسعه و بررسی

- رنگ‌ها و فونت در `src/styles/tokens.css` تعریف می‌شوند. کلاس‌های Tailwind را در HTML بنویسید. الگوهای تکراری دو صفحه در stylesheet مشترک قرار دارند.
- تعاملات از `src/main.js` راه‌اندازی می‌شوند. رفتار هر بخش در `src/modules` و پیام‌های اعتبارسنجی فرم در `src/locales` قرار دارد.
- با `npm run check` تحلیل کد، قالب‌بندی، تست‌های ساختار، build و تست تعاملی فرم و گالری اجرا می‌شوند. تست مرورگر از Chrome نصب‌شده استفاده می‌کند. برای انتخاب مرورگر دیگری از خانوادهٔ Chromium، مسیر فایل اجرایی را در `CHROME_PATH` قرار دهید.
- برای اجرای آزمون‌های تصویری مانند `node scripts/hero-check.mjs`، سرور توسعه را باز نگه دارید. نشانی پیش‌فرض تست‌ها `http://localhost:5173/` است و با `TEST_URL` تغییر می‌کند.

فرم مشاوره در این نسخه نمایشی است. ثبت درخواست مشتری برای انتشار عمومی به اتصال فرم به سرویس دریافت درخواست نیاز دارد.
